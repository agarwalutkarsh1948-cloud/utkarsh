# MR > UTKARSH Portfolio Website

A high-performance personal portfolio built with HTML, CSS, and JavaScript.

## Features
- Full preloader word-cycle transition
- Responsive Hero section with Video mask
- Interactive expandable portfolio card carousel
- Interactive service accordion
- Hover image preview for experience timeline items
- Fully responsive layout across Desktop, Tablet, and Mobile

## How to Run Locally

### Prerequisites
- Visual Studio Code installed
- "Live Server" Extension installed in VS Code

### Steps
1. Download or clone this repository folder into your local environment.
2. Open VS Code, select **File > Open Folder**, and open the `portfolio` directory.
3. The hero section plays `assets/video/hero.mp4` (grey background baked in, matches `#e5e5e5`). Replace that file to change it; `assets/images/utkarsh-profile.jpg` is kept as a still backup.
4. Click on `index.html`.
5. Right-click inside the `index.html` editor window and select **"Open with Live Server"**.
